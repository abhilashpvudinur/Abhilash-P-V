# Abhilash P V — Portfolio

A responsive, static portfolio website for GitHub Pages.

## Contents
- `index.html` — portfolio website
- `assets/` — portfolio cover, dashboard screenshots, and four photography portfolio PDFs
- `source-export/` — original Notion-exported HTML pages for reference

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `abhilash-portfolio`).
2. Upload the contents of this folder to the repository root (make sure `index.html` is at the root).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish and open the URL shown on the Pages settings screen.

## Notes
- The site is plain HTML and CSS; no build step is required.
- The two live Looker Studio dashboard links from the original portfolio are retained.
- The LinkedIn link is a general LinkedIn URL because the export did not provide a profile URL. Replace it with the exact profile URL before publishing if desired.
